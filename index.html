Selected work

Evaluation for a sports-data LLM agent

Led the evaluation platform for a pre-release agent. Evaluations on 54 service changes informed model and provider decisions and caught regressions before release. A scoring stack of deterministic fact checks plus an LLM judge cut structured-output failures from 8.0% to 0 of 1,744.

Structured retrieval for LLM agents

Added a GraphQL retrieval path alongside the legacy feed workflow. In a controlled 177-case A/B test, run errors fell 83%, input tokens 46% and median latency 30%.

Reliable LLM services

Built and operate the service behind match summaries in the Opta Arena football app: four live data feeds, multi-provider routing with fallbacks, circuit breakers and cost caps. Nine months in production at a 0.18% 5xx rate.

Legal risk in corporate speech

MSc dissertation, Edinburgh. A leakage audit falsified the quote-level hypothesis and led to a calibrated case-level model, released with an open dataset of 24K quotes across 125 federal cases.
