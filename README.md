# jakedugan.com

Static site built by GitHub Pages (Jekyll). No server code, database or login.

- Homepage: `index.html`
- New post: add `_posts/YYYY-MM-DD-short-title.md` with a `title:` (and optional `description:`) in the front matter, then commit. It appears on the homepage and at `/writing/` within a minute or two.
- Drafts: `_drafts/` is never published.
- Feed: `/feed.xml`
